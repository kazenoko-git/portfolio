# Extra website content

Add `.md` or `.mdx` files under `projects/`, `papers/`, `blogs/` (or `writing/`),
or `certifications/` (or `certificates/`). These entries take priority over imported
repository documentation with the same collection and slug. A project can also
match an imported repository through its `repoUrl`.

See [the publishing guide](../docs/publishing.md) for frontmatter and examples.
